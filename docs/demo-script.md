# ClassBridge 5-Minute Demo

## Before Presenting

1. Open the deployed ClassBridge URL in one browser tab.
2. Use the teacher role in `Real-Time [Offline] Class` or `Solo Studio`.
3. Keep the browser zoom at 100% and close unrelated tabs.
4. Do not depend on live microphone audio. Use the built-in sample replay as the reliable path.

## Timed Presentation

### 0:00-0:35: Problem and Product

Say:

> Fast STEM lectures create two barriers: students may miss the explanation, and a single translation language does not work for every learner. ClassBridge turns one lecture into live captions, each student's preferred vernacular, and revision material.

Point to the language bar and the classroom mode tabs. Mention that the teacher controls the spoken source language while each student chooses a personal subtitle language.

### 0:35-1:35: Live Captions

1. Click `Sample: ML & Optimization` in the bottom dock or the sample replay control.
2. Let the sample populate the caption pane.
3. Point to:
   - English source text.
   - Vernacular translation.
   - Timestamp.
   - Confidence badge.
   - Highlighted STEM terms.

Say:

> The lecture is transcribed into timestamped dual-language captions. Technical terms are preserved through the STEM glossary instead of being translated literally.

For a stronger language demonstration, select Malayalam or Tamil in the student language control and show the same segment changing without changing the teacher's source language.

### 1:35-2:20: Student-Specific Language

Say:

> The teacher can speak English and select the classroom source language. Student A can read Tamil while Student B reads Malayalam. Their choices are independent, so one student's preference never changes another student's captions.

If two browser windows are available, open the student invite link in the second window and select a different preferred language. Otherwise demonstrate the language selector in the current student view.

### 2:20-3:15: Grounded Q&A

1. Open `BridgeAI Tutor` or the tutor panel.
2. Ask: `What is gradient descent?`
3. Show the answer and click its timestamp citation.

Say:

> The tutor searches this lecture transcript first. The answer cites the exact lecture segment, and clicking the citation jumps back to the source caption.

Optionally ask an unrelated question and point out that it is labelled as outside the current lecture.

### 3:15-4:10: Study Guide and Diagram

1. Click `Study Guide`.
2. Open the `Overview` tab briefly.
3. Open `Concept Map`.
4. Show `Definitions`, `Formulas`, and `Flashcards` if time allows.

Say:

> The transcript becomes a structured revision guide. The concept map is grounded in concepts detected in this lecture, while formulas are included only when supported by the transcript.

Mention the `Download PDF` button as the offline revision deliverable.

### 4:10-4:40: Lecture History

1. Close the study guide.
2. Click `History` in the bottom dock or Online Class toolbar.
3. Select `Restore` on the saved lecture.

Say:

> Completed transcript data is retained locally in the browser. A student can return later, restore the lecture, and continue revising instead of losing the session at refresh.

### 4:40-5:00: Close

Say:

> ClassBridge connects the full learning loop: speech recognition, technical translation, live comprehension, grounded questions, and durable revision notes. It helps students understand the lecture now and retain it later.

## Emergency Fallback

- If the sample does not load, type this into the lecture input and submit it:
  `Gradient descent updates model parameters using the learning rate and loss function.`
- If the backend is unavailable, the browser demo fallback still supports sample captions, glossary terms, study-guide generation, concept map display, and PDF fallback.
- If time is short, skip Q&A and show only `Captions -> Study Guide -> Concept Map -> History`.

## Three Facts to Remember

- One teacher stream, many student language preferences.
- Every answer and note is grounded in the lecture transcript.
- The output is not only translation: it becomes reusable study material.
